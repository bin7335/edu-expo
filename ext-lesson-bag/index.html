📚 수업 준비하다 보면 탭이 이렇게…

위키백과, 에듀넷, 과학관 누리집… 수업마다 여는 탭을 매번 다시 찾지 마세요.

→ 지금 창의 탭을 수업 세트로 저장하고, 수업 시간에 새 창으로 한 번에 열어요.

세트 안 링크는 순서 바꾸기·지우기·추가가 되고, JSON 파일로 내보내 다른 컴퓨터로 옮길 수 있어요.

QR로 학생 기기에 링크 전달

▦ QR은 왜 '링크 하나'가 기본인가요?

  • 서버 없이 세트 전체를 여는 공유 주소는 만들 수 없어요.
  • 그래서 기본은 링크 하나 — 학생이 카메라로 찍으면 바로 열려요.
  • 목록 전체(글자)도 고를 수 있어요. 찍으면 주소 목록이 글로 보여요.

⚙️ 내 크롬에 설치 (3단계)

  1. 위 zip 내려받기 → 압축 풀기
  2. chrome://extensions → 오른쪽 위 개발자 모드 켜기
  3. 압축해제된 확장 프로그램 로드 → 푼 폴더 고르기

🔐 권한은 탭·저장소 두 가지뿐. 세트는 내 컴퓨터에만 저장돼요.
