통신문은 갔는데, 내용은 닿지 않았다면

📄 지금은

  • 한국어 통신문을 번역기에 넣어 따로따로 보내기
  • 날짜·금액이 번역 과정에서 틀어질까 걱정
  • 회신이 오지 않아 다시 전화로 확인

🌏 다가온 통신문에서는

  • 블록으로 한 번 쓰면 언어별 버전이 나란히
  • 날짜·금액·기한은 아이콘 + 숫자로 언어와 상관없이
  • 회신은 각자 언어로, 교사에게는 한국어로 도착
FEATURES

주요 기능

🧱

정해진 블록으로 쓰기

일시·장소·준비물·비용·회신을 칸으로 채워 빠뜨림 없이 씁니다.

🌐

언어별 버전 나란히

가정마다 설정한 언어로 받고, 탭을 눌러 다른 언어와 비교할 수 있습니다.

🔢

언어 없는 핵심 정보

날짜·금액·기한은 번역하지 않고 아이콘과 숫자로 그대로 보여 줍니다.

↩️

회신 자동 모으기

보호자가 자기 언어로 누른 동의·미동의가 교사 화면에 한국어로 모입니다.

HOW IT WORKS

사용 흐름 3단계

STEP 1 · 교사

블록으로 통신문 쓰기

제목과 블록만 채우면 됩니다. 문장은 짧고 쉽게 쓰도록 안내합니다.

STEP 2 · 검수

번역 확인

언어별 버전을 다문화 담당·통역 지원 인력이 확인한 뒤 보냅니다.

STEP 3 · 가정

내 언어로 읽고 회신

보호자는 익숙한 언어로 읽고 버튼 한 번으로 회신합니다.

※ 미리보기의 번역문은 시연용 예시로, 실제 번역은 전문 검수가 필요합니다. 학교·장소·일정은 모두 가상이며, 화면 안에서만 동작하고 어떤 정보도 전송하거나 저장하지 않습니다.
