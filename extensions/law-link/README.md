# ⚖️ 법령 콕 (크롬 확장)

공문·안내문을 읽다가 나오는 법령 이름을 **드래그 → 우클릭 → 「법령 콕: 국가법령정보센터에서 찾기」** 하면
국가법령정보센터(law.go.kr)의 그 법령이 새 탭으로 바로 열립니다. 뒤에 `제N조`가 붙어 있으면 **그 조문까지** 엽니다.

```
학교폭력예방법 제17조  →  https://www.law.go.kr/법령/학교폭력예방 및 대책에 관한 법률/제17조
교육기본법            →  https://www.law.go.kr/법령/교육기본법
교육과정 편성 (법령명이 아님) →  국가법령정보센터 검색 결과
```

## 기능
- **우클릭 메뉴**: 고른 글자에서 법령명(+시행령·시행규칙)과 `제N조(의N)`을 알아내 바로 열기. 법령명이 아니면 검색 결과를 엽니다.
- **팝업**: 툴바의 아이콘을 누르면 지금 페이지에 나온 법령명을 모아 목록과 링크로 보여 줍니다(조문 바로가기 포함, 여러 번 나오면 ×N).
- **약칭 사전 내장**(27개): 학교폭력예방법, 교원지위법, 청탁금지법·김영란법, 이해충돌방지법, 개인정보보호법, 아동학대처벌법, 정보공개법, 학교안전법, 특수교육법, 초중등교육법, 지방교육자치법, 교육환경법, 학원법, 청소년성보호법(아청법), 성폭력처벌법, 장애인차별금지법, 재난안전법, 지방계약법, 기초학력보장법 등 → 정식 법령명으로 바꿔 엽니다.
- 「」로 묶인 이름, 띄어쓰기·가운뎃점이 다른 표기(`초·중등교육법`, `초중등교육법`)도 알아봅니다. '방법·학습법'처럼 법령이 아닌 낱말은 거릅니다.
- `…조례`, `…교육규칙`은 자치법규 주소(`/자치법규/이름`)로 엽니다.

## 설치 (3단계)
1. `law-link.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 압축을 푼 폴더 선택

## 권한과 개인정보 — 최소 권한
| 권한 | 이유 |
|---|---|
| `contextMenus` | 글자를 고르고 우클릭했을 때 "법령 콕" 메뉴를 보여 주기 |
| `activeTab` | **팝업을 누른 그 탭에서만**, 누른 순간에만 페이지 글을 읽기 |
| `scripting` | 팝업을 눌렀을 때 그 탭의 글(본문 텍스트)을 한 번 읽어 오기 |

- 모든 사이트에 상주하는 스크립트(`<all_urls>`)가 **없습니다.** 설치 경고도 최소입니다.
- **어떤 데이터도 저장하거나 밖으로 보내지 않습니다.** 네트워크 요청 코드가 없고, 원격 코드·CDN도 쓰지 않습니다. 하는 일은 law.go.kr 주소를 만들어 새 탭으로 여는 것뿐입니다.
- 한계: 크롬 설정 화면·웹 스토어·PDF 뷰어에서는 팝업 목록이 동작하지 않습니다(우클릭 메뉴는 대부분 동작). 사전에 없는 법령명은 이름을 그대로 넣어 열기 때문에, 이름이 정확하지 않으면 국가법령정보센터에서 "없음"이 나올 수 있어요. 그때는 팝업 목록의 **🔍 검색**을 쓰세요.
