# 🏷️ 출처 꼬리표 (크롬 확장)

웹페이지 글을 복사(Ctrl+C)하면 클립보드에 **복사한 글 + 출처 한 줄**이 함께 들어갑니다.
학생이 조사 학습을 할 때 "어디서 가져왔는지" 밝히는 습관을 자연스럽게 기르는 디지털 시민성 연습 도구입니다.

```
물은 증발하고 응결하여 구름이 됩니다.

[출처] 「물의 순환 알아보기」, 햇살 과학관, https://example.org/water, 2026년 11월 7일 확인
```

## 기능
- 복사할 때 출처 자동 첨부: 「글 제목」, 사이트 이름, 주소(URL), 확인한 날짜
- 주소는 기본으로 `?` 뒤(검색어·추적 값)와 `#` 뒤를 떼고 넣습니다. 게시판 글 번호처럼 꼭 필요하면 팝업의 **주소의 ?·# 뒷부분까지 넣기**를 켜세요.
- 형식 2가지 (팝업에서 선택)
  - **초등 쉬운 형식**: `[출처] 「제목」, 사이트, URL, 2026년 11월 7일 확인`
  - **APA 비슷한 형식**: `저자. (연도). 제목. 사이트. 2026년 11월 7일 확인, URL` (저자·연도를 모르면 제목을 앞에, `(n.d.)`)
- 팝업 켜기/끄기 스위치, **이 페이지 출처 복사** 버튼
- **출처 목록**: 최근 30개(같은 주소는 하나로), **모두 복사**(번호 목록) · **지우기** · 하나씩 빼기
- 입력칸(글쓰기 칸) 안에서 복사하거나, 사이트가 직접 복사를 처리하는 경우에는 건드리지 않습니다.

## 설치 (3단계)
1. `source-tag.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 압축을 푼 폴더 선택

> 설치 전부터 열려 있던 탭은 한 번 **새로고침**해야 복사 꼬리표가 붙습니다.

## 권한과 개인정보 — 왜 "모든 사이트"인가요?
| 권한 | 이유 |
|---|---|
| 콘텐츠 스크립트 `http://*/*`, `https://*/*` | 학생이 **어느 사이트에서** 복사할지 미리 알 수 없어서, 모든 웹페이지(http·https만, 파일·설정 화면 제외)에서 `copy`(복사) 순간을 기다려야 합니다. 설치할 때 "모든 웹사이트의 데이터 읽기 및 변경" 경고가 나오는 이유입니다. |
| `storage` | 켜기/끄기, 형식, 출처 목록을 **내 컴퓨터의** `chrome.storage.local`에 저장 |
| `activeTab` | 팝업을 열었을 때 지금 탭의 제목·주소를 읽어 "이 페이지 출처 복사"를 만들기 위해 |

- 이 확장은 **어떤 데이터도 외부로 보내지 않습니다.** 네트워크 요청 코드가 전혀 없고, 원격 코드·CDN도 쓰지 않습니다.
- 페이지에서 읽는 것은 복사하는 순간의 **제목, 사이트 이름(og:site_name), 저자·발행연도 메타 정보, 주소**뿐입니다.
- 복사한 **글 내용은 저장하지 않습니다.** 출처 목록에는 제목·사이트·주소·날짜만 남습니다.
- 한계: 페이지 안의 iframe(끼워 넣은 다른 페이지)과 크롬 설정 화면·웹 스토어에서는 동작하지 않습니다.
