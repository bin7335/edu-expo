# 딸깍 QR (크롬 확장)

툴바 아이콘을 **한 번 누르면**(또는 `Alt+Q`) 지금 보고 있는 페이지 주소가 **큰 QR 코드**로 뜹니다.
수업 중 "이 사이트 들어가 보세요"를 주소 불러 주기 대신 QR 한 장으로 끝내는 교사용 도구입니다.

## 기능
- 팝업: 페이지 **제목 + 주소** 표시, QR 크게
- **🖥️ 전체 화면으로 크게 보기**: 새 탭에 화면 가득 QR + 제목 + 짧은 주소 (교실 TV·전자칠판용)
- **⬇ PNG 저장**: QR 아래에 제목·주소가 들어간 그림 파일로 저장 (인쇄해서 붙이기)
- **📋 주소 복사**
- **주소 고치기 칸**: 고치면 QR이 바로 바뀜. `example.org/a`처럼 써도 `https://`를 붙여 줌. ↺ 버튼으로 탭 주소로 되돌리기
- **추적 꼬리표 지우기**(기본 켜짐): `utm_*`, `fbclid`, `gclid`, `msclkid`, 유튜브 `si` 등 광고·유입 추적 파라미터를 빼서 QR을 덜 촘촘하게
- 주소가 300자보다 길면 "촘촘해요" 경고
- `chrome://` 설정 화면, 새 탭, `file://` 내 컴퓨터 파일 등은 학생 폰에서 열 수 없으므로 안내 문구를 보여 주고 주소를 직접 넣을 수 있게 함
- 단축키 `Alt+Q`: 팝업 열기 (`chrome://extensions/shortcuts`에서 바꿀 수 있음. 다른 프로그램이 이미 쓰고 있으면 비어 있을 수 있어요)

## 설치 (3단계)
1. `page-qr.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 압축을 푼 폴더 선택

> 툴바의 퍼즐(🧩) 버튼 → 딸깍 QR 옆 **고정(📌)** 을 누르면 아이콘이 항상 보여 "딸깍"이 쉬워집니다.

## 권한과 개인정보
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 **누른 순간에만**, **그 탭 하나의** 제목과 주소를 읽습니다. 팝업에서 `chrome.tabs.query({active:true, currentWindow:true})`로 읽으며, activeTab이 부여되면 그 탭의 `url`·`title`을 읽을 수 있어 `tabs` 권한(모든 탭 주소 열람)은 필요 없습니다. 설치할 때 "모든 웹사이트" 경고도 나오지 않습니다. |

- 이 확장은 **어떤 데이터도 외부로 보내지 않습니다.** 네트워크 요청 코드가 없고, QR은 확장 안의 코드(`qr-core.js`)로 내 컴퓨터에서 직접 그립니다. 원격 코드·CDN·서버 없음.
- 아무것도 저장하지 않습니다(`storage` 권한 없음).
- 크게 보기 페이지(`big.html?u=…`)는 `http://`·`https://` 주소만 받아들이고, 제목·주소는 글자(textContent)로만 화면에 넣습니다.

## 파일
| 파일 | 역할 |
|---|---|
| `manifest.json` | Manifest V3 설정 (권한: `activeTab`, 단축키 `Alt+Q`) |
| `qr-core.js` | QR 인코더 + 주소 정리(추적 꼬리표 지우기)·그리기 로직 (체험 페이지와 같은 코드) |
| `popup-ui.js` / `popup.css` | 팝업·크게 보기 화면 (체험 페이지와 같은 코드) |
| `popup.html` / `popup.js` | 팝업 (탭 제목·주소 읽기) |
| `big.html` / `big.js` | 전체 화면 크게 보기 |
| `icon16/48/128.png` | 아이콘 |

QR 인코더는 이 저장소 `qr-maker`의 인코더를 그대로 옮겼습니다. ISO/IEC 18004 표준과 Project Nayuki "QR Code generator library"(MIT License)의 공개된 설계를 참고했습니다.
