# 투명 판서판 (크롬 확장)

어떤 웹페이지 위에서든 투명한 판서막을 씌워 펜·형광펜·레이저 포인터·도형·스포트라이트로 바로 설명하는 수업용 도구입니다.

## 설치 (3단계)
1. `board-pen.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 풀어 둔 폴더(`manifest.json`이 있는 폴더)를 선택합니다.

## 쓰는 법
- 켜기/끄기: 도구 모음 아이콘 → **판서 켜기 / 끄기**, 또는 `Alt+Shift+D`
  - 단축키가 다른 확장과 겹치면 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다.
- 도구: `P` 펜(빨강·파랑·검정, 굵기 3단계) · `H` 형광펜 · `E` 지우개(획 단위) · `L` 레이저(꼬리가 사라짐) · `A` 화살표 · `R` 네모 · `S` 조명(스포트라이트) · `V` 통과
- `Ctrl+Z` 되돌리기 · 🗑️ 전체 지우기(되돌리기로 복구) · `[` `]` 굵기/조명 크기 · `Esc` 통과 → 한 번 더 누르면 끄기
- **통과** 모드: 필기는 그대로 두고 페이지를 클릭·스크롤할 수 있습니다. 필기는 글자 위치에 붙어 스크롤을 따라갑니다.
- 도구 모음 왼쪽 `⠿`를 끌어 위치를 옮길 수 있습니다.

## 권한과 개인정보
- `activeTab`, `scripting`만 사용합니다. 아이콘을 누르거나 단축키를 누른 **그 탭에만** 판서 코드를 넣습니다(모든 사이트 접근 권한 없음).
- 필기는 저장·전송하지 않습니다. 탭을 새로 고치면 사라집니다.
- 크롬 설정·웹스토어 같은 보호된 페이지에서는 동작하지 않습니다. 내 컴퓨터의 파일(`file://`)에서 쓰려면 확장 세부정보에서 **파일 URL에 대한 액세스 허용**을 켜세요.

## 파일
`manifest.json` · `background.js`(단축키) · `popup.html/js`(팝업) · `overlay.js`(판서 기능 본체, 체험 페이지와 같은 코드) · `icon16/48/128.png`
