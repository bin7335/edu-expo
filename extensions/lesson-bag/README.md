# 🎒 수업 가방 (크롬 확장)

지금 창에 열려 있는 탭들을 **"3교시 과학 - 물의 순환"** 같은 이름의 **수업 세트**로 담아 두고,
수업 시간에 클릭 한 번으로 **새 창에 한꺼번에** 다시 엽니다.

## 기능
- **가방에 담기**: 지금 창의 탭을 세트로 저장 (목록에서 골라 담기 가능. 탭을 Ctrl/Shift로 여러 개 골라 두었으면 그 탭만 미리 선택)
  - 크롬 설정 화면·새 탭 같은 웹페이지가 아닌 탭은 자동으로 빠집니다.
- **열기**: 세트의 링크를 새 창 하나에 모두 열기
- **편집**: 세트 이름 바꾸기, 링크 순서 ▲▼, 링크 지우기, 주소 붙여넣어 추가
- **QR**: 세트의 링크 하나(기본) 또는 목록 전체(글자)를 QR 코드로 — 인터넷 없이 확장 안에서 직접 그림
- **JSON 내보내기/가져오기**: 팝업의 [⚙ 크게 편집 · JSON 백업] → 편집 페이지에서 파일로 백업·다른 컴퓨터로 옮기기

## QR은 왜 "링크 하나"가 기본인가요?
세트 전체를 한 번에 여는 **공유 주소**를 만들려면 세트를 올려 둘 서버가 필요합니다. 이 확장은 서버를 쓰지 않으므로,
- **링크 하나**(기본): 학생 휴대폰·태블릿 카메라로 찍으면 그 링크가 **바로 열립니다.** 수업 첫 활동 링크를 나눠 줄 때 가장 실용적입니다.
- **목록 전체(글자)**: 세트 이름과 주소 목록이 **글자**로 담깁니다. 찍으면 목록이 보이고, 주소를 눌러 하나씩 엽니다. (`data:` 주소는 카메라 앱이 열어 주지 않아서 일반 글자를 씁니다.) 링크가 아주 많으면 QR에 다 들어가지 않으니 링크 하나를 고르세요.

## 설치 (3단계)
1. `lesson-bag.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 압축을 푼 폴더 선택

## 권한과 개인정보
| 권한 | 이유 |
|---|---|
| `tabs` | 지금 창의 탭 제목·주소를 읽어 세트로 담고, 세트를 새 창으로 열기 위해 |
| `storage` | 세트를 **내 컴퓨터의** `chrome.storage.local`에 저장 |

- 웹페이지 내용은 읽지 않습니다(콘텐츠 스크립트 없음). 외부 전송·원격 코드·CDN 없음.
- JSON 백업 파일은 내가 직접 내려받는 파일로만 만들어집니다.

## 파일
| 파일 | 역할 |
|---|---|
| `manifest.json` | Manifest V3 설정 |
| `bag-core.js` | 세트 데이터·JSON·QR 인코더 (체험 페이지와 같은 코드) |
| `bag-ui.js` / `bag.css` | 화면 (팝업·편집 페이지·체험 페이지 공통) |
| `adapter.js` | 크롬 탭·저장소 연결 |
| `popup.html` / `popup.js` | 툴바 팝업 |
| `options.html` / `options.js` | 크게 편집 · JSON 백업 페이지 |
| `icon16/48/128.png` | 아이콘 |

QR 인코더는 ISO/IEC 18004 표준과 Project Nayuki "QR Code generator library"(MIT License)의 공개 설계를 참고해 직접 작성했습니다.
