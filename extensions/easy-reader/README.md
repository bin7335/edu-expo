# 술술 읽기 (크롬 확장)

어떤 웹페이지든 글자 크기·줄 간격·배경색을 바꾸고, 줄 가리개와 소리 내어 읽기(단어 따라가기)로 학생의 읽기를 돕는 도우미입니다.

## 설치 (3단계)
1. `easy-reader.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 풀어 둔 폴더(`manifest.json`이 있는 폴더)를 선택합니다.

## 쓰는 법
- 켜기/끄기: 도구 모음 아이콘 → **읽기 도우미 켜기 / 끄기**, 또는 `Alt+Shift+R`
  - 단축키가 겹치면 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다.
- 글자 크기(100-200%) · 줄 간격 · 글자 간격 슬라이더, **읽기 쉬운 글꼴**(또렷한 고딕체)
- **줄 가리개**: 마우스(손가락)를 따라 움직이는 띠만 밝게 두고 나머지를 어둡게. 띠 높이 조절
- **배경색**: 기본 / 크림 / 어두움
- **소리 내어 읽기**: 글을 드래그해 고르고 🔊 → 한국어 음성으로 읽고, 읽는 문장과 단어를 노랗게 따라갑니다. 고른 글이 없으면 화면 가운데 문단을 읽습니다. 빠르기 0.6-1.6배.
  - 단어 따라가기는 음성이 단어 위치를 알려 줄 때만 됩니다(Windows의 `Microsoft Heami` 같은 내 컴퓨터 음성은 대체로 지원). 지원하지 않는 음성이면 문장 단위로만 표시합니다.
- 패널 `—` 접기(효과 유지) · `✕` 끄기(원래 페이지로) · 머리줄을 끌어 위치 이동
- 설정은 자동 저장됩니다. 기본은 모든 사이트 공통, **이 사이트만 따로 기억**을 켜면 그 사이트 전용으로 저장됩니다.
  - 모든 사이트 접근 권한을 쓰지 않으므로, 페이지를 새로 열면 아이콘(또는 단축키)을 한 번 눌러야 저장된 설정이 적용됩니다.

## 권한과 개인정보
- `activeTab`, `scripting`, `storage`만 사용합니다. 아이콘·단축키를 누른 그 탭에만 코드를 넣습니다.
- 설정은 이 컴퓨터의 `chrome.storage.local`에만 저장하고, 외부로 보내지 않습니다. 음성 읽기는 크롬 내장 음성(speechSynthesis)을 씁니다.
- 크롬 설정·웹스토어 같은 보호된 페이지에서는 동작하지 않습니다. `file://` 문서에서 쓰려면 확장 세부정보에서 **파일 URL에 대한 액세스 허용**을 켜세요.

## 파일
`manifest.json` · `background.js`(단축키) · `popup.html/js`(팝업) · `reader.js`(읽기 도우미 본체, 체험 페이지와 같은 코드) · `icon16/48/128.png`
